# 开源前隐私审查

审查日期：2026-10-01。目标是准备可公开的源码副本，同时保留正式工作台的个人数据。

## 审查范围

检查当前已跟踪源码、未提交的源码修改、发布所需图标、测试、项目目录中的私有文件类别，以及本地所有 Git refs 可达的历史提交。发布候选使用单独目录和全新的根提交，不复制开发仓库的任何历史。

没有读取或修改浏览器个人数据，没有读取本机实际聊天正文、Obsidian 正文或社交附件；数据目录仅核对存在状态和内容摘要。用户已选择 MIT 并授权公开发布；发布仅针对重新导出并复核后的独立仓库。

## 发现与处理

| 发现 | 发布处理 |
| --- | --- |
| 缓存、SQLite、截图、备份位于正式项目目录 | 逐文件允许清单排除；补充 Git 忽略规则 |
| 旧教程包含实际本机 Token 汇总和个人使用案例 | 整个旧教程排除；仅加忽略规则不足以清理旧历史 |
| 图片生成 JSON 含用户名和本机来源路径 | JSON 与原始图片排除；仅发布经过复核的应用图标 |
| 后端与一个测试包含实际项目目录 | 删除冗余硬编码后端候选，测试改为合成的 Unicode 路径 |
| 旧 Git 提交包含作者邮箱与旧文件内容 | 导出只读当前允许文件，完全不复制 Git 历史 |
| 静态服务可返回私有目录文件，HEAD 也可访问 | 增加静态资源允许范围及本机请求来源检查，使用临时环境验证 |
| 推文模块内置第三方全文和固定媒体示例 | 从源码删除内置示例及自动填充、正文和媒体替换；已有用户记录保持读取兼容 |

已有私人数据不删除、不迁移、不覆盖。开源导出不扫描用户主目录、不复制外部数据目录。

## 验证结果

- 30 项语法检查、11 项前端模块生命周期测试和 149 项 Python 回归检查通过；Python 检查中 5 项符号链接用例因当前 Windows 权限跳过，真实 Windows junction 与硬链接防护测试通过。
- 推文存储的 7 项内存 localStorage 和 VM 测试通过，验证新环境为空、已有正文与媒体保留、旧示例不被补写和无效 JSON 不被空数据覆盖。
- 54 个明确允许的源码、MIT 许可证和测试文件通过发布预检，单元测试验证私有文件排除、凭证阻断、不覆盖既有输出和 ZIP SHA256 一致性。
- 本机应用目录中 5 个已知数据文件的存在状态与内容摘要在验证前后均一致。未在正式浏览器执行数据操作或页面验证。
- 本次未重启正在运行的工作台；源码中的服务保护在下一次重启后生效。

## 保证的边界

扫描没有发现真实凭证的常见形状；这不代表任意格式凭证和全部自然语言隐私都能被自动识别。安全判断只针对本次实际导出并复核的文件，不包括未来修改、现有私人项目文件夹、旧远端、浏览器导出和正式页面截图。

已通过经过身份验证的 GitHub API 确认原仓库为私有；原仓库继续保留作私人开发环境。公开目标是另建仓库，先以私有状态核对远端文件、MIT 许可证和全新提交，再切换为公开。第三方依赖保留各自许可证，运行时用户导入的内容不属于本项目源码许可范围。
